Effective PPI, not file metadata

The calculation divides pixel width and height by the full physical artwork area, including the bleed you enter, and reports the limiting axis. Embedded DPI metadata does not override those dimensions.

Why the threshold is editable

Printers, materials, screening processes, image types, scaling rules, and review stages differ. This tool does not claim that one PPI value is universally acceptable. Enter the requirement supplied for the exact component and production route.

Final preflight still matters

A pass says only that the browser-readable image meets the configured pixel threshold. Confirm color mode, profiles, transparency, vector/raster treatment, bleed, safe areas, file format, and supplier templates separately. Reconcile named files first with the Delivery Manifest Checker.
