Why use cumulative entries?

Cumulative rows let the checker reject decreases and derive each entered daily change consistently. Record the same platform total at a consistent daily cutoff.

A run rate is not a forecast model

The linear finish simply extends the recent entered pace. Launch spikes, middle-period slowdowns, final-day lifts, cancellations, platform discovery, and external promotion are not predicted.

Use the next action, not the headline

If the recent pace is below the required run rate, inspect source mix in the Referral Performance Comparator and measurable stages in the Conversion Funnel Analyzer before assuming more spend is the answer.
