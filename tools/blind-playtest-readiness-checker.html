Blind means the prototype speaks for itself

A blind test checks whether new players can prepare, interpret, and finish the game with the provided materials. It is not the same as a guided session where the designer can teach, clarify intent, or recover a missed setup step.

What counts as a blocker

Missing rules, components, setup, end condition, or a way to capture confusion make the outcome difficult to interpret. A page marked “needs revision” is different: it can be deliberately tested if the group is small and the observation goal is narrow. Record every intervention rather than treating it as invisible help.

After the screen

Use the Rulebook Sections Reference to check the purpose of each section, then create a focused agenda with the Session Planner. This screen cannot replace a real blind test; it only helps you avoid sending an untestable packet.
