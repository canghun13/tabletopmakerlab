Long-form rows preserve the path

Each player has one row per scoring category. That keeps objectives, engines, bonuses, penalties, or any creator-defined path visible instead of reducing a game to final totals.

Share and winner lift are different

Point share shows how much of the recorded scoring system a category supplies. Winner lift compares average category points among winners with the average among all players. A category can be common without separating winners—or rare and strongly associated with them.

Association is not causation

Winning players may score more in a category because they were already ahead, because categories correlate, or because experienced players favor the same strategy. Treat a flag as a prompt for controlled retesting, not an instruction to nerf a mechanic.
