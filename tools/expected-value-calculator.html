Calculation method

For mutually exclusive outcomes covering one complete event, expected value is μ = Σ pᵢxᵢ. Outcome values may be negative losses, zero or positive rewards, including decimals. Standard deviation is √(Σ pᵢ(xᵢ − μ)²), in the same units as the values. Each weighted row contributes pᵢxᵢ; this is a long-run average, not a guaranteed single-event result.

Assumptions and limits

This is a tabletop design scenario using your inputs, not a prediction of player experience. Check your game's exact rules and edge cases before finalizing a design. Enter finite values and probabilities from 0 to 100%. Probabilities must total 100%; missing probability mass, overlapping events and arbitrary weights are not a complete distribution. Tables outside a 0.00000001 percentage-point roundoff tolerance are blocked, not normalized. Accepted arithmetic roundoff alone is rescaled to 100%. Extremely large magnitudes or probabilities that overflow or underflow the calculation must be rescaled. Floating-point results are rounded to three decimal places, with scientific notation for magnitudes at least 10¹²; this is not arbitrary-precision arithmetic.

Read average and spread together

A 50% loss of −4 and a 50% reward of +4 have expectation 0 and standard deviation 4. A sure result of 0 also averages 0 but has no spread. A 25% loss of −2 and a 75% reward of +6 average 4, with standard deviation about 3.464. Include the zero-result outcome explicitly when it has a chance of occurring; a blank is not a zero.

Use the result in a design decision

Two choices can have the same expected value but very different possible ranges. Zero-probability rows contribute nothing and do not set the minimum or maximum possible value. Use the spread and weighted rows to decide whether the game wants volatility, a safety floor, or a catch-up mechanism. Add outcome keeps the table editable; Reset restores the starting values in existing rows, including zero-value, zero-probability defaults in added rows. Incomplete or invalid tables cannot be copied or printed as reports.
