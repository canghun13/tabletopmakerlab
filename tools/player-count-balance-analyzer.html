Two lenses, not one balance score

Duration catches pacing and downtime shifts; score spread catches how far apart final results become. They answer different questions, so the analyzer shows both instead of blending them into a synthetic grade.

Baseline behavior is explicit

Each rules version uses the player count you enter. If that count is absent, the report falls back to the lowest recorded count for that version rather than silently mixing versions.

Interpret spread in context

A larger spread can mean runaway leaders, but it can also reflect experienced versus new players or a scoring scale that grows with count. Review session notes and repeat comparable groups before adjusting the design.
