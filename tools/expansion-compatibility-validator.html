No proprietary compatibility rules are assumed

The tool does not decide whether two mechanics are balanced or whether a particular commercial product is supported. It verifies the structural contract you express in columns.

How collisions and replacements differ

An expansion row that reuses a base ID is an error unless it explicitly names that base ID as its replacement target. Missing dependencies, self-dependencies, missing replacement targets, duplicate IDs, and replacement type changes are reported separately.
