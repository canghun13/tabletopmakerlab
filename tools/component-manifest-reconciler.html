Use IDs to distinguish rename from replacement

A stable component ID lets the tool identify a renamed row as the same component, while a missing ID or an extra ID indicates a structural manifest change. Quantities are compared as explicit creator-entered values.

Approval still belongs to the project team

The tool does not know whether an extra component is a bonus, whether a rename is approved, or whether a changed quantity is intentional. It exposes the discrepancy and the source row so that decision can be documented.
