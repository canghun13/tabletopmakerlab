Release changes are records, not text lines

A raw text diff becomes noisy when rows or columns are reordered. This tool pairs records by the ID column, then reports added and removed IDs plus the exact fields changed on surviving IDs.

Keep operational columns out of player-facing notes

Ignore timestamps, internal notes, or workflow status fields that should not appear as design changes. Duplicate or missing IDs remain errors because they make a stable comparison ambiguous.
