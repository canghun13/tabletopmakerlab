Why the opening cumulative count matters

A period can begin below a breakpoint and end above it. Applying either the old or new percentage to every current-period unit can misstate the result. This tool calculates the overlap between the current unit interval and each entered contract band.

Worked reading

If 4,500 cumulative units were already reported and the current period adds 1,800, only the first 500 current units remain in a 5,000-unit first tier. The next 1,300 belong to the second tier. The table shows those allocations explicitly.

Choose the correct threshold convention

Some agreements use gross units, net units after returns, revenue, print runs, statement number, or another measure. This page supports cumulative net units only. Convert or choose another method only when the agreement clearly supports it.

Limits

The tool does not supply normal rates or interpret a contract. It also does not apply advances, reserves, taxes, currency conversion, or payment thresholds. Use the actual definitions and seek professional advice when needed.
