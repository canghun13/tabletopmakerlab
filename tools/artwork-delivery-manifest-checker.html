What an exact filename check prevents

It catches missing exports, files that were renamed outside the manifest, accidental duplicate expectations, wrong extensions, and unexplained extras before reviewers guess which version belongs to which component.

What this checker cannot inspect

The browser does not approve layers, linked fonts, spot colors, color profiles, bleed, visual quality, embedded assets, or rights. Use the Image Resolution & Print Size Checker for browser-readable image dimensions and the production partner’s native preflight process for final files.

Manifest discipline

Keep one exact filename and one stable asset ID per deliverable. If a component legitimately needs several files, give each deliverable its own manifest row and filename.
