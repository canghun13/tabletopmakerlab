Prototype to Manufacturing Checklist

A staged handoff checklist for tabletop creators.

Prototype before production

A production prototype is a test of decisions, not just a display copy. Lock the card count, board folds, token sizes, box interior, insert assumptions, and assembly sequence you need to verify. Label any placeholder component so a reviewer does not mistake it for an approved production choice.

How to apply it

A useful test case is a sleeved setup-and-teardown: can players return every component to the box without bending cards or forcing the lid? Photograph the packed prototype, measure the stacks, and note which components required an improvised bag or spacer.

Questions and decisions

Send partners a single version-controlled component list with dimensions, material, finish, quantity, and tolerance questions. Ask what cannot be sampled at prototype scale, such as final die-cut registration, mass-assembly speed, or freight carton behavior.
